about flashflow

what it doesflashflow is a quiet text-first study app for recall cards, cloze blanks, quizzes, and small supporting images.
why it helpsit keeps the card central while saving banks, ratings, skipped cards, queues, settings, and review history in your browser.

timed stepstimed review is on by default for new state. if no card is due but reviewable cards exist, flashflow keeps studying instead of forcing a wait.
backupcards csv exports the active bank. progress json restores banks, ratings, queue, and settings.
lecture flowturn notes into regular, cloze, quiz, image, or mixed rows. study the bank, rate each reveal, then filter weak cards before the exam.
regular flowfront appears first, reveal shows the answer, rating sets the next return. again/hard/good/easy follow the timed minutes in general settings.
cloze flow[[hidden terms]] become blanks. typing accepts the term or full sentence, and reveal underlines the restored answer.
quiz flowsingle-answer choices grade immediately. multi-answer quizzes let you select several choices, then check the exact set.
image flowpublic drive links in image fields become bounded card images. tap an image for preview, then reveal and rate like any card.
manual flowwhen you want focused cleanup, use filters for again, hard, good, easy, skipped, learned, or repeating cards.
private imagesgoogle drive images must be shared as anyone with the link.
samplesif sample loading fails from file://, run through a local server or import the sample file manually.
quiz importschoice columns must start at A and continue without gaps. multi-answer choices must match the exact correct set.
duplicate notesif explanation repeats the answer exactly, flashflow hides it during review.
ai promptcopy this prompt into an ai tool to generate a flashflow-ready table.
Create a FlashFlow-compatible mixed study bank as a CSV table. Use this header: type,front,back,text,stem,A,B,C,D,E,answer,accepted,explanation,tags,image,imageBack. Include regular cards, cloze cards using [[answer]], single-answer quiz rows, multi-answer quiz rows using A|C syntax, tags, accepted answers, concise explanations, and optional public Google Drive image links. Keep explanations short and do not repeat the answer exactly.
